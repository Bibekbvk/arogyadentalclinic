## ✨ Features

- **Modern Medical UI/UX:** Clean medical teal/blue palette with Google Fonts (Plus Jakarta Sans & Noto Sans Devanagari).
- **Mobile Responsive:** Fast loading, responsive layout, glassmorphic sticky navigation, and slide-out mobile drawer menu.
- **7 Core Dental Services:**
  1. Scaling & Polishing (Teeth Cleaning)
  2. Root Canal Treatment (RCT)
  3. Tooth Extractions & Impactions (Wisdom Tooth)
  4. Dental Crowns, Bridges & Implants
  5. Braces & Aligners (Orthodontics)
  6. Cosmetic Dentistry & Teeth Whitening
  7. Pediatric (Kids) Dental Care
- **Interactive Appointment Booking System:**
  - Real-time Nepal 10-digit phone number format validation (`98XXXXXXXX` / `97XXXXXXXX`).
  - Date constraints enforcing today or future dates.
  - Generates instant **Booking Confirmed Modal** with Reference ID.
  - **1-Click WhatsApp Dispatch:** Automatically formats booking details into a WhatsApp message sent directly to clinic reception (+977 9801109099).
- **Location & Working Hours:** Detailed directions from Mahendra Highway, opening hours table (Sun–Fri 8 AM – 7 PM), and responsive Google Maps embed.
- **Floating WhatsApp Widget:** Fixed bottom-right chat button with animated pulse.

## 🚀 Local Development

To run the project locally:

```bash
# Clone the repository
git clone https://github.com/Bibekbvk/arogyadentalclinic.git

# Navigate into directory
cd arogyadentalclinic

# Start a local static server
python -m http.server 8080
# or
npx serve .
```

Then open `http://localhost:8080` in your browser.
